Offline ও Background নোট

Whisper Small-এর কয়েকশ MB model file এক HTML-এর ভিতরে এমবেড করা নেই। প্রথমবার runtime ও model internet থেকে download হয়ে browser cache-এ থাকবে। Cache মুছে গেলে আবার download লাগতে পারে। এটিই browser-based “inbuilt/cached model”; সম্পূর্ণ offline installer নয়।

Web Worker UI সচল রাখে এবং tab background-এ গেলে কিছু সময় কাজ চলতে পারে। Android Chrome ব্যাটারি/RAM বাঁচাতে tab suspend করতে পারে। তাই screen on ও tab খোলা রাখুন। Speed ফোনের CPU/RAM ও audio length-এর ওপর নির্ভরশীল।
