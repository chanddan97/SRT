২. তৈরি হওয়া SRT

গুরুত্বপূর্ণ: Offline ও Background

প্রথমবার CDN runtime এবং প্রায় কয়েকশ MB মডেল ফাইল ডাউনলোড হবে। ব্রাউজারের cache-এ সংরক্ষণের চেষ্টা করা হয়; cache মুছে গেলে বা browser storage পরিষ্কার হলে আবার download লাগতে পারে। একটিমাত্র HTML ফাইলে runtime ও Whisper model এমবেড করা নেই।

প্রসেসিং আলাদা Web Worker-এ চলে, তাই একই ট্যাবের UI সচল থাকবে এবং অন্য অ্যাপে গেলে কিছু সময় চলতে পারে। তবে Android Chrome/ফোন OS ব্যাটারি বা মেমোরির কারণে background tab suspend/বন্ধ করতে পারে। স্ক্রিন বন্ধ বা অ্যাপ বদলালেও ১০০% চলবে—এমন নিশ্চয়তা নেই। কাজের সময় ট্যাব খোলা রাখাই ভালো।

দীর্ঘ অডিওতে RAM ও সময় বেশি লাগবে। Whisper Small মডেল পুরোনো/কম RAM ফোনে ধীর হতে পারে। ফলাফল শুনে subtitle ঠিক করে নিন—বিশেষ নাম, আঞ্চলিক উচ্চারণ ও শব্দে ভুল হতে পারে।

আপনার অডিও ফাইল কোনো সার্ভারে আপলোড করা হয় না; inference আপনার ব্রাউজারেই হয়। মডেল/runtime ডাউনলোডের সময় সংশ্লিষ্ট CDN/Hugging Face হোস্টে সংযোগ হবে।
